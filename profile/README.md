## PHREEQC Interactive Highlights

- **Speciation:** PHREEQC Interactive speciation splits a measured water into dissolved species so a class can see more than the total calcium or the total carbonate on the lab sheet.
- **Saturation Index:** PHREEQC Interactive saturation index shows whether a common mineral is undersaturated or oversaturated in that same water.
- **Batch Reaction:** PHREEQC Interactive batch reaction follows a closed beaker change, such as adding a known mineral or changing the gas contact the exercise names.
- **Inverse Model:** PHREEQC Interactive inverse model looks for a plausible mineral and gas balance between two waters you already analyzed.
- **Mixing Run:** PHREEQC Interactive mixing run combines two defined solutions in a proportion you choose and shows the mixed result.

## What Is PHREEQC Interactive

PHREEQC Interactive is a geochemical calculation helper with a form-based screen for the PHREEQC engine. You bring a water analysis from a lab, a textbook, or a small field study. PHREEQC Interactive speciation is usually the first run: totals go in, species and activities come out. PHREEQC Interactive saturation index rides with that run and tells you how the water stands relative to minerals the course has already named, such as calcite or gypsum.

PHREEQC Interactive batch reaction is the next step when the exercise changes the water on purpose. You keep the starting solution, apply the reaction the assignment describes, and read the new totals. PHREEQC Interactive mixing run is simpler to explain: two known waters, one fraction, one result. PHREEQC Interactive inverse model is the quieter, harder question, used when you have two analyses and want a mass-balance story that could connect them. All of these belong to samples and minerals you are studying, not to a guess about a system you have not measured.

A student can do one speciation before lunch and a mixing example after class. A small project can keep PHREEQC Interactive saturation index beside the field sheet. The input stays visible, the selected output stays short, and the database named by the instructor stays the one you use. PHREEQC Interactive speciation, PHREEQC Interactive batch reaction, and PHREEQC Interactive mixing run cover most early assignments. PHREEQC Interactive inverse model waits until two waters and a mineral list are both in your notes.

## Starting with PHREEQC Interactive

Prerequisites: A compatible computer, a water analysis you may use, and permission to run PHREEQC Interactive.

1. **Prepare:** Write the totals, pH, and temperature in the units your notes require.
2. **Define The Solution:** Enter that water and run PHREEQC Interactive speciation.
3. **Read Minerals:** In the same output, read PHREEQC Interactive saturation index for the minerals the class listed.
4. **Change One Thing:** Build a small PHREEQC Interactive batch reaction that the assignment describes, then compare it with the first result.
5. **Blend Two Waters:** If you have a second analysis, try PHREEQC Interactive mixing run at one clear fraction.
6. **Leave Inverse For Later:** Open PHREEQC Interactive inverse model only when both waters and the allowed mineral list are written down.
